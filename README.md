# MyCV

This repository contains a personal CV/resume webpage for Lukas Kelley. The site is a static, single-page portfolio/CV built with plain HTML and CSS, designed to present a concise overview of his background, skills, education, work experience, and contact information.

## Overview

The page includes:

- A modern dark-themed personal landing section
- About me summary
- Skills and competency highlights
- Education timeline
- Work experience details
- Contact links for email, phone, and GitHub
- A responsive layout for desktop and mobile devices

## Project files

- `index.html` — main CV page and inline styling
- `profile_pic.jpg` — profile portrait image used in the hero section
- `README.md` — project documentation

## View locally

Because this is a static website, no build process is required.

1. Open `index.html` directly in a browser, or
2. Serve the project locally:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This project is suitable for GitHub Pages or any static hosting provider. If you want to publish it with GitHub Pages, use the repository root as the site source and keep `index.html` at the top level.
